The problem

Starting a channel is editing, not ideas.

CapCut will let you finish a video with a track that cannot live on YouTube. A credit meter will cut you off mid-batch. Firehose automation without a human gate is how channels get reviewed for inauthentic content. ReelForge is the other product: local, YouTube-safe, and you click Accept.

How it works

Four moves. No timeline.

A JSON storyboard plus a deterministic renderer. The language model never moves frames.

01

Topic

Type a brief or paste a full script. Pick faceless facts, listicle, explainer, storytime, product, commentary, or news.

MP4 plus title, first-150-char hook, chapters from 0:00, tags, thumbs, SRT, asset credits, synthetic-content reminder.

Inside the app

Everything a new channel actually needs.

You still approve the script

Draft, edit hook/beats/captions, then Accept. There is no silent path from topic to MP4. That is how the channel stays monetizable.

The first 3 seconds are a feature

Required hook scene: on-screen claim, VO start, picture change. No logo open. No “welcome back.”

Kokoro, then the Mac

Kokoro-FastAPI at :8880/v1/audio/speech. Named voices, locked per project, pause at commas. AVSpeech fallback. Piper is not embedded.

Pexels, not Unsplash firehose

Videos API with Authorization header. Per-beat match, skip generic first-page clips, per-channel id blacklist. Unsplash is manual and off.

YouTube-safe audio

Bundled original beds or a folder you import. Duck 8–12 dB under VO. Never CapCut/TikTok tracks. License ledger on every project.

Upload pack, not just an MP4

Title ≤70, hook in the first 150 characters, chapters from 0:00, tags, thumbs, SRT, credits, synthetic-content reminder.

Captions in the Shorts safe zone

3–6 words on Viral Hook. ~15% top and bottom clear, right-rail clear. Karaoke/pop. Editable on the script desk. SRT export.

Fourteen presets, no fake experts

We do not ship doctor, lawyer, finance-advisor, or political-expert impersonation presets.

FAQ

Straight answers.

Is this Mac only?

Mac is the native SwiftUI app. Windows is a desktop app (Python + ffmpeg) with the same Accept-gate pipeline. Neither one asks you to install a node graph or 80GB of weights. Core works offline with zero local diffusion models.

Does my data leave the machine?

Projects live in Application Support. Exports land in Movies/ReelForge. Optional keys call Pexels or Unsplash. Optional localhost calls stay on your network. There is no cloud render farm.

Can I get a YouTube strike?

We never download CapCut, TikTok, or copyrighted tracks. Beds are original-safe or from a folder you import. Pexels credits go in the ledger. You remain the publisher. Tick YouTube’s altered/synthetic checkbox when the voice is generated.

Do I need API keys?

No. Draft + Accept still finishes with system TTS, cards, and a bundled bed. A free Pexels key unlocks moving B-roll. Unsplash is manual and off. Kokoro on :8880 is preferred TTS. Model Manager is optional and never downloads weights for you.

Will it upload for me?

Not yet. Settings can store a YouTube Data API key. The Upload button is disabled until OAuth exists. We will not fake a successful upload.
